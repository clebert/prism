# Prism

A World of Warcraft Forever addon that marks self-buff action buttons when the buff is active.

<img src="prism.jpg" alt="Prism" width="400">

Prism has no configuration window. Rules live in code and use client spell data, so every locale
works.

The first rule is this. When a self-buff spell such as Battle Shout is on an action bar and the
player has that buff, the button is checked and dimmed.

## Installation

- Download Prism from [CurseForge](https://www.curseforge.com/wow/addons/prism)
- Extract the folder into `World of Warcraft/_classic_beta_/Interface/AddOns/`
- Restart WoW or type `/reload` if the game is already open
